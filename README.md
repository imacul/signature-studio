# Signature Studio

A browser-based signature creator. Open `index.html` in a browser to use it locally.

Live site: https://studiosign.vercel.app

## Contributing

Contributions are welcome. See [CONTRIBUTING.md](CONTRIBUTING.md) for how to
fork the repository and submit a pull request. Open an issue to discuss a change.
Pushing to `main` deploys the latest version through Vercel.
